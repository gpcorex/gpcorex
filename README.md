# GPCoreX

Construí la herramienta que necesitás.

GPCoreX nace como una plataforma modular de soluciones reutilizables.

La idea es resolver problemas y no rubros específicos.

## Módulos iniciales

- Pedidos y trabajos
- Turnos y agenda
- Stock
- Clientes
- Caja
- Documentos
- Personal
- Seguimiento

## Concepto

Elegir módulos y combinarlos como piezas tipo Lego para construir soluciones adaptables a distintos negocios.
